# Metric Book Transcriber

Jupyter-ноутбук для транскрибування записів про народження з історичних метричних книг за допомогою Google Gemini API.

## Огляд

Цей проєкт обробляє зображення сторінок історичних метричних книг і використовує Gemini для вилучення/транскрибування інформації із записів.

Проєкт дозволяє:

1. Обирати серед різних AI-моделей, замінюючи одну на іншу, коли вичерпується безкоштовний план
2. Подавати моделі власне референсне зображення з відповідним вручну транскрибованим текстом/таблицею
3. Налаштовувати промт для AI відповідно до власних вимог
4. Задавати власні стовпці/поля в результуючій таблиці залежно від оброблюваних зображень і власних побажань
5. Обрізати зображення з попереднім переглядом, щоб AI обробляв лише потрібну частину сторінки, виключаючи зайвий текст
6. Перевіряти якість транскрибування після першого транскрибованого зображення
7. Використовувати checkpointing — тобто коли квота AI вичерпується, наступного разу обробка починається з ще не оброблених зображень
8. Експортувати результат у CSV-файл

Наразі використовується модель Gemini `gemini-3.1-flash-lite`. Її можна замінити на будь-яку іншу модель (`GEMINI_MODEL_NAME`). Для вибору серед моделей, спеціалізованих на розпізнаванні рукописного тексту, використано [цей рейтинг](https://www.genea.ca/rankings/). Однак він порівнює продуктивність моделей лише на англійських/німецьких рукописних текстах.

Також була протестована модель `google/gemini-3.7-flash`, але вона виявилася значно повільнішою, і безкоштовний план вичерпувався приблизно за 20 зображень. Хоча вона краще розпізнавала номер сторінки, це аж ніяк не компенсувало її недоліків загалом.

У результатах роботи обох моделей виявлено галюцинації — інколи з'являвся зовсім інший текст. Отриманий CSV-файл усе ще потребує ретельної постобробки. Кращих результатів можна досягти методом проб і помилок, підбираючи модель / промт / референс під власні потреби.

## Вимоги

- Python 3.10+
- JupyterLab або Jupyter Notebook
- Ключ Google Gemini API

## Встановлення

Клонуйте репозиторій:

```bash
git clone https://github.com/Owlly/metric_book_transcriber.git
cd metric_book_transcriber
```

Створіть віртуальне середовище:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Встановіть залежності:

```bash
pip install -r requirements.txt
```

### API-ключ

Щоб отримати ключ Gemini API:

1. Перейдіть до [Google AI Studio](https://aistudio.google.com/) і увійдіть за допомогою свого облікового запису Google.
2. Прийміть умови користування, якщо ви заходите вперше.
3. Натисніть **Get API key** на бічній панелі зліва або в нижньому лівому куті екрана.
4. Натисніть кнопку **Create API key**. Оберіть наявний проєкт або створіть новий, коли з'явиться відповідний запит.
5. Скопіюйте новостворений буквено-цифровий ключ і зберігайте його **у безпечному місці**.

Створіть локальний файл `.env` на основі наданого прикладу:

```bash
cp .env.example .env
```

Потім відредагуйте `.env`:

```
GEMINI_API_KEY=your_actual_api_key
```

Файл `.env` навмисно виключено з Git, і його **заборонено** комітити чи передавати іншим.

## Використання

У своєму віртуальному середовищі запустіть JupyterLab:

```bash
jupyter lab
```

Відкрийте:

```
metric_book_transcriber_birth_resize-3.1flash.ipynb
```

Ноутбук використовує одне референсне зображення (`007767501_01087.jpeg`) та кілька прикладних зображень у папці `images/metr_book/`.

Референсне зображення використовується для "подачі" Gemini разом із відповідною попередньо транскрибованою таблицею з нього — `metr_book_birth_ref.csv`. Краще використовувати власну пару зображення й CSV (підготовлену вручну), стиль якої більше відповідає вашим цільовим зображенням.

Помістіть свої зображення в папку `images/metr_book/` для обробки за допомогою Gemini. Пройдіть по ноутбуку крок за кроком. Перегляньте та відредагуйте отриманий CSV-файл.
